📁 Файловый менеджер

Приложение для поиска файлов на компьютере по заданному расширению с использованием графического интерфейса Windows Forms.

🎯 Цель проекта

Разработать приложение с графическим интерфейсом для поиска файлов по заданным критериям с возможностью просмотра результатов, отслеживания времени выполнения и остановки поиска.

📋 Описание проекта

Файловый менеджер — приложение, разработанное на языке C#, которое позволяет искать файлы в выбранной директории и всех её вложенных папках.

Программа отображает результаты поиска в виде дерева каталогов, позволяя пользователю удобно просматривать найденные файлы.

🚀 Возможности

🔍 Поиск файлов по заданному расширению (например, txt, docx, pdf).

📂 Выбор начальной директории для поиска.

🌳 Отображение найденных файлов в древовидной структуре.

📊 Подсчёт количества найденных файлов и общего количества просмотренных файлов.

⏱️ Отображение времени выполнения поиска.

⏹️ Возможность остановить поиск в любой момент.

🖥️ Простой графический интерфейс.

🛠️ Используемые технологии

Язык программирования: C#

Платформа: .NET

Графический интерфейс: Windows Forms

Среда разработки: Visual Studio

⚙️ Принцип работы

Пользователь запускает приложение.

Указывает начальную директорию для поиска.

Вводит расширение интересующих файлов.

Нажимает кнопку «Поиск».

Программа последовательно проверяет файлы во всех вложенных директориях.

Найденные файлы отображаются в виде дерева папок.

Во время поиска отображается затраченное время.

После завершения поиска пользователь получает информацию о количестве найденных и просмотренных файлов.

При необходимости поиск можно остановить кнопкой «Остановить».
